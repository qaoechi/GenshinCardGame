# genshinCardGame
Unity(C#)로 개발한 TCG 카드 게임 프로젝트입니다. 완성하지 못했지만, Unity사용법, UI 구성, 카드 시스템 설계 등을 구현하며 많은 것을 배웠습니다.<br>
[데모 플레이 보러가기](https://youtu.be/FaSofwXbutI)

## 기능
+ 덱 저장
+ 카드 뽑기
+ playerPrefs 저장

## 문제점 및 배운 점
#### 1. 사전 준비 및 설계의 부족
+ ##### 명확한 계획 없이 개발을 시작해 구조를 자주 수정해야 했음
+ ##### 팀원마다 게임 흐름 이해가 달라 충돌 발생
+ ##### 요구사항 명세서 및 기획서의 필요성을 느낌
#### 2. 프로그래밍 지식 부족
+ ##### 객체 지향 개념에 대한 부족한 이해로 비효율적인 코드
+ ##### Event Handler, Delegate 등을 사용할 때 흐름 파악이 어려움
#### 3. 배운 점
+ ##### 팀 단위 협업 경험
+ ##### Unity 개발 경험
+ ###### 사전 설계의 중요성을 체감
